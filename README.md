# глиф.

Концепт-сайт вымышленной шрифтовой студии «Глиф» для портфолио. ТЗ и журнал решений — в [BRIEF.md](BRIEF.md).

```bash
npm install
npm run dev        # dev-сервер
npm run build      # сборка в dist/
npm run fonts      # пересобрать WOFF2 из fonts-src/ (нужны fonttools и brotli)
```

Панель настройки: добавьте `?debug` или `#debug` к адресу.

Шрифты: Roboto Flex, Literata, JetBrains Mono — SIL Open Font License, тексты лицензий в `fonts-src/licenses/`.
Студия вымышлена, шрифты под вымышленными именами — реальные открытые гарнитуры.
